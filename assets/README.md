# Free character assets

`notsims-human.glb` contains a MakeHuman/MPFB-derived clothed human, a shared
53-bone game-engine skeleton, three hair meshes, and 26 original reusable motion clips. The vocabulary and loop/one-shot metadata
are defined in `src/presentation/clips.js` and checked by the build. Sleep uses a relaxed skeletal pose with the game
renderer positioning the character horizontally on the bed. Transitions blend
between clips; standing returns to Idle.

The model is generated by `scripts/export-character.py` using **MPFB 2.0.18**
(source commit `3af0cd5a2ffba072e93a34e5f6f494fdc4813ddf`) and Blender 4.5.4 LTS.
The runtime uses only the exported graphical asset; MPFB/Blender program code is
not bundled in the game. Core MakeHuman graphical assets and derived output are
CC0, separate from MPFB's GPL source code license. The included CC0 declaration
is in `CC0-1.0.txt`.

Sources:

- MPFB: https://github.com/makehumancommunity/mpfb2
- License policy: https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md
- System assets: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- CC0 ZIP: https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
- ZIP SHA256: `b542127a8e25547c7c29c19f2d1d2adb9a664c80396ecd694095dbc8028a0107`

The system assets used are `male_casualsuit01`, `shoes01`, `short01`, `long01`,
`afro01`, `low-poly` eyes, `brown_eye.png`, and
`young_lightskinned_male_diffuse.png` (converted to a neutral tintable texture).
Each is listed as CC0 by the asset pack. Clothing and hair are rigged to the
same skeleton. Skin, shirt and hair materials are tintable at runtime.

To regenerate, download a portable Blender 4.5 build from the official Blender
release directory, check out the pinned MPFB commit, and unzip the CC0 system
asset pack. No paid download, account, or API key is required.

```sh
MPFB_SOURCE=/path/to/mpfb2/src \
MPFB_ASSETS=/path/to/unzipped-system-assets \
CHARACTER_OUT=/path/to/output \
blender --background --python scripts/export-character.py
```

Copy the resulting `notsims-human.glb` and `character-metadata.json` into this
directory. The exporter is pinned to Blender 4.5.4; exports start at frame zero
and sample at 24 fps. The current asset is 6.8 MB against a 12 MB mobile budget.
Run `node scripts/check-character.mjs` to validate the asset and metadata. Authoring `.blend`
files and source textures need not be deployed. The optional preview scripts
produce offline asset/geometry QA images; they do not certify browser rendering.

Three.js is MIT licensed. Builds include its license in `vendor/three/LICENSE`.
Furniture, terrain, and the rest of the game art are generated by project code.
