# Save schema and migrations

CURRENT_SAVE_VERSION remains **1**. This refactor changes no persisted IDs,
coordinates, costs or field representation. The browser storage key remains
`notsims.save.v1`; no save is overwritten merely by loading it.

`validateSave(raw)` in persistence/save.js runs four steps:

1. Parse JSON (or clone a plain input). Reject string input over 2,000,000 UTF-8
   bytes. The browser adapter also rejects oversized files before reading them.
2. Clone and migrate through MIGRATIONS, keyed by source version. Each pure step
   must return exactly version + 1. Missing steps and unsupported future versions
   fail before canonical validation. No version is inferred from missing fields.
3. Validate canonical data using schema.js: character, bounds, known furniture and
   career IDs, unique furniture IDs, world coordinates, needs and progress.
4. Rebuild runtime state: clear queued and non-work actions, reconstruct valid
   in-progress work using canonical career total/pay, and derive nextId from IDs.

The state field ownership table is in [system-boundaries](system-boundaries.md).
`serializeSave` produces canonical loadable JSON without modifying the live state.
The browser continues exporting its live v1 state, preserving legacy behavior;
loading always rebuilds transients. Unknown harmless extra fields retain legacy
validation behavior; this is not a stricter replacement save schema.

## Adding a version

Add a pure migration in persistence/migrations and register it by old version.
Update CURRENT_SAVE_VERSION and canonical schema validation together. Never use
DOM, clocks, RNG, live state or storage in a migration. Freeze a real old save
fixture and test the full chain, invalid migrated fields, input immutability,
future-version rejection and load/save idempotence before shipping. Current
synthetic tests exercise ordered v1→v2→v3 steps without inventing a production
schema bump. They also exercise missing and malformed migration steps.

The frozen save-v1.json was generated by the original engine at c457d625. It
contains the starter house and a barista shift 30 minutes in. The original engine
is frozen separately as test-only text for differential regression checks.
